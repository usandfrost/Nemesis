Download Nemesis Beta 2

Nemesis is free firmware for the Randomwaves Drumboy Pro. It is an independent project, not made by Randomwaves.

This is Beta 2, an early test version. It works on the devices it has been tried on, but expect bugs, and things may change in the next version.

Please read this first

Nemesis is free software, given as it is, with no warranty of any kind. You use it at your own risk. Keep a copy of your SD card: a power cut during a save, or a failing card, can lose data, and installing other firmware on your device is your own choice. The makers accept no liability for lost data or for damage to cards or devices.

If you do not accept this, do not install Nemesis.

What you need

  • A Drumboy Pro and its SD card. Your card already holds the samples. Nemesis uses them where they are, and this package does not change them.
  • A computer with Windows or macOS, and a way to put the card in it.
  • About 10 minutes.

Using a different card? It must be formatted FAT32, so 32 GB or smaller is simplest, and it must hold a copy of everything on your Drumboy's own card. Cards bigger than 32 GB usually come as exFAT, which the Drumboy cannot read.

What is in this package

  • Drumboy_Pro_Fw_Nemesis_B2.bin: the firmware
  • CATHODE: a folder with the presets and wavetables (CATHODE is the engine's name)
  • INSTALL.txt: this text
  • LICENSES.txt: the disclaimer and the licences
  • COPYING.txt: the GNU General Public License

Installing on Windows

  1. Switch the Drumboy off and take out the card. Put the card in your computer. If Windows offers to scan, fix or format the card, say no.
  2. Make a backup. Open the card in File Explorer, select everything, and copy it to a new folder on your computer. Do not skip this.
  3. Right-click the Nemesis zip file and choose Extract All. Work from the extracted folder, not from inside the zip.
  4. Copy the .bin file and the CATHODE folder to the top level of the card, next to the Sample and System folders. Do not put them inside another folder.
  5. If Windows says files already exist, this is not a first install: see UPDATING below.
  6. In File Explorer, right-click the card and choose Eject. Wait until it says it is safe, then take the card out.

Installing on macOS

  1. Switch the Drumboy off and take out the card. Put the card in your Mac. If macOS offers to repair or initialize the card, say no.
  2. Make a backup. Open the card in Finder, select everything, and copy it to a new folder on your Mac. Do not skip this.
  3. Double-click the Nemesis zip file to unpack it.
  4. Copy the .bin file and the CATHODE folder to the top level of the card, next to the Sample and System folders. Do not put them inside another folder.
  5. If Finder says CATHODE already exists, press Stop. This is not a first install: see UPDATING below. Choosing Replace would delete your saved projects.
  6. In Finder, click the eject button next to the card. Wait until the card disappears from the sidebar, then take it out.

macOS leaves small hidden files on the card, with names starting with "._". They are harmless, and the Drumboy ignores them.

Finishing the install, on both

  1. Put the card in the Drumboy and switch it on.
  2. Wait about 20 seconds. The Drumboy's own installer runs first: a green box says UPDATING FIRMWARE, with V1.01 under it (the file's own number, not the Nemesis version), and then FIRMWARE UPDATED. Do not switch off during this step.
  3. The Nemesis picture appears, and then the sequencer screen.
  4. The installer empties System/Firmware and moves the .bin file into it, so it only installs once. That deletes the original firmware file from the card, which is one more reason to keep your backup.

The first save

Starting up does not write to the card, with one exception: if a power cut stopped a preset being replaced, the next start finishes that first. The first time you save after switching on, Nemesis reads through the whole card to check that it is safe to write to. That takes some seconds, and longer on a full card. The sound keeps playing.

If a save says the card has a problem, Nemesis has found damage and will not write to the card. It still plays. Put the card in a computer and run a disk check (Windows: right-click the card, Properties, Tools, Check. macOS: Disk Utility, First Aid). Nemesis never repairs a card itself.

Updating to a new version

Copy only the new .bin file to the top level of the card, then eject and switch on as above. Your projects and presets stay as they are.

To get new presets or wavetables as well, copy the files inside the package's CATHODE/PRESETS and CATHODE/WT into the same folders on the card. Copy the files, not the CATHODE folder itself.

Going back to the original firmware

Your original firmware file is in your backup, in its System/Firmware folder, with a name like Drumboy_Pro_Fw_01_02.bin. Copy it to the top level of the card, eject, and switch on. If you have no backup, get it from Randomwaves.

Your projects made with Nemesis stay in the CATHODE folder but the original firmware will not read them. Your samples are not touched.

If something goes wrong

  • Nothing changes when you switch on: check that the .bin file is at the top level of the card, and that its name still starts with Drumboy_Pro_Fw and ends with .bin. Windows can hide the .bin ending, so do not rename the file. The installer does not see a name of more than 31 characters.
  • A red box says FIRMWARE ERROR: the install failed, and the installer has deleted the .bin file from the card. Copy it to the card again from the package and switch on. If it happens again, go back to the original firmware, as above.
  • No presets or wavetables: check that CATHODE is at the top level, with PRESETS and WT inside it.
  • The card is not read at all: check it is FAT32, using your computer's disk properties or Disk Utility.
  • Anything else: put your backup back on the card and go back to the original firmware, as above.
